# test-data · 导入格式测试用例

本目录存放 Open-Balance 六种导入格式的测试样本文件，供
`tests/importer.test.ts` 自动化验证，也可以手动在「数据管理 →
选择文件导入」中试用。

| 文件 | 格式 | 模拟来源 | 内容概要 |
|------|------|----------|----------|
| `wechat-bill.csv` | 微信支付账单 | 微信 → 钱包 → 账单导出 | 19笔交易（工资/消费/零钱通转入/理财通申购），带标题行 |
| `alipay-bill.csv` | 支付宝账单 | 支付宝 → 账单导出 | 15笔交易（余额宝自动转入/收益/基金定投扣款/消费） |
| `suishouji.csv` | 随手记 | 随手记 → 导出数据 | 11笔交易，双账户（工商/招商银行卡），含定投 |
| `cmb-bank-statement.csv` | 银行流水 | 招商银行网银导出 | 11笔流水（6个月工资+房贷还款），含期末余额列 |
| `generic-assets.csv` | 通用 CSV | 任意资产清单表格 | 6行资产快照，靠列名自动映射 |
| `open-balance-backup.json` | Open-Balance 备份 | 本工具导出 | 3项资产 + 1项负债 + 家庭档案 |

## 每种格式的预期解析结果（供测试断言参考）

### wechat-bill.csv
- 检测格式：`wechat`
- 19 笔交易；收入 ¥62,300 / 支出 ¥14,904
- 资产 2 项：
  - 零钱通（现金及存款/货币基金）¥19,526
  - 微信零钱（现金及存款/活期存款）¥32,870
- 警告 1 条：理财通净申购 ¥5,000 无法从流水推定持仓

### alipay-bill.csv
- 检测格式：`alipay`
- 15 笔交易；收入 ¥24,256.80 / 支出 ¥6,762.20
- 资产 2 项：
  - 余额宝（现金及存款/货币基金）¥20,057
  - 支付宝余额（现金及存款/活期存款）¥3,438
- 警告 1 条：基金定投净扣款 ¥6,000 无法从流水推定持仓

### suishouji.csv
- 检测格式：`suishouji`
- 11 笔交易；收入 ¥50,500 / 支出 ¥4,807.50
- 资产 2 项（按账户聚合）：
  - 工商银行储蓄 ¥43,349
  - 招商银行储蓄 ¥2,344

### cmb-bank-statement.csv
- 检测格式：`bank-generic`
- 11 笔交易；收入 ¥108,000 / 支出 ¥26,286.50
- 资产 1 项：招商银行储蓄，**以流水最后一行余额为准** ¥249,714
- 警告 1 条：房贷还款净支出无法从流水推定负债余额

### generic-assets.csv
- 检测格式：`csv-generic`
- 资产 6 项，合计 ¥3,382,000，大类由「大类」列直接映射

### open-balance-backup.json
- 检测格式：`open-balance-json`
- 资产 3 项 + 额外携带 1 项负债与家庭档案（导入时一并恢复）
